# 配色色卡 ColorKit

在浏览器里选色、调色、自动配色，做成色卡并导出。纯静态网页，所有数据只保存在你自己的浏览器里，图片不会上传。

**在线使用：** https://lydiafanfan.github.io/color-kit/

## 功能

| 页面 | 做什么 |
|---|---|
| **工作台** | 2–10 色的色卡。按空格随机生成（可选生成方式），锁定的颜色保留不变；拖动调换顺序，两色之间插入中间色，每个颜色可查看明暗阶梯；撤销 / 重做；按明暗排序 |
| 颜色编辑 | 饱和度 / 明度方块 + 色相条，HSB / HSL / RGB / OKLCH / CMYK 滑杆，可粘贴任意格式的色值，可用屏幕吸管（Chrome / Edge）。显示所有格式的色值（点击复制）、最接近的传统色名、色阶、黑字和白字的对比度 |
| 整体调色 | 同时调整所有颜色的色相、饱和度、明暗、对比度和冷暖，有调整前后对比 |
| 效果预览 | 网页界面、海报、拼布 / 条纹 / 格纹 / 波点、穿搭、3D 打印（每个颜色匹配最接近的拓竹 PLA 耗材，并给出多色钥匙扣示意）、渐变（附 CSS）、WCAG 对比度矩阵、色盲模拟 |
| **自动配色** | 色轮可在美术 RYB 和光学 RGB 之间切换。色彩理论配色有 9 种：单色、类似、互补、分裂互补、三角、矩形、正方形、复合、明暗阶梯。风格配色有 13 种：莫兰迪、马卡龙、多巴胺、Y2K、美拉德、大地色、复古、赛博霓虹、清新、极简、暗夜、新中式、渐变。另有色阶、加白、加黑、加灰四组变化 |
| **图片取色** | 拖入、选择或粘贴图片，按主色 / 鲜艳 / 柔和 / 深沉 / 多样自动提取 2–10 色，可拖动图上的圆点微调；吸管点选时有放大镜 |
| **色库** | 中国传统色、日本传统色、50 多组流行配色（Y2K、多巴胺、美拉德、莫兰迪、新中式……）、Pantone 年度色、网红名色、拓竹耗材色，可按色系 / 名称筛选 |
| **我的色卡** | 保存、重命名、导出、删除，可以 JSON 备份和导入 |
| 导出 | PNG 色卡图（卡片式或竖条式）、CSS 变量、SCSS、Tailwind、JSON、文本、SVG、Adobe .ase（Photoshop / Illustrator / Procreate） |
| 分享 | 生成带颜色的链接，打开就能载入这组配色 |

传统色、年度色、耗材色都是常见流传的屏幕近似值，印刷或买耗材时请以实物色卡为准。

## 本地运行

使用了 ES 模块，需要通过本地服务器打开：

```bash
cd color-kit
python3 -m http.server 5175
```

然后打开 http://localhost:5175

## 文件

```
index.html      页面骨架
style.css       样式（浅色 / 深色）
js/app.js       路由与各页面
js/color.js     颜色换算、对比度、色盲模拟
js/harmony.js   自动配色、随机生成、整体调色、传统色命名
js/picker.js    取色器
js/wheel.js     色轮
js/extract.js   图片主色提取（OKLab k-means）
js/preview.js   效果预览
js/export.js    导出
js/store.js     状态、撤销、本地存储
js/data.js      色库数据
```
